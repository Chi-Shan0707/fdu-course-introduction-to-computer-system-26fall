# 课程课件 (Course Slides)

本目录归档整理了复旦大学《计算机系统基础》（Introduction to Computer System, ICS）课程的讲义与幻灯片，供课程学习与离线查阅。

---

## 课件清单

| 文件名 | 内容划分 | 主要涉及模块（参考 CS:APP） |
| :--- | :--- | :--- |
| [`ICS-上.pdf`](./ICS-上.pdf) | 第一部分（基础与数据表示） | 计算机系统漫游、信息表示与处理（数制转换、整数补码、浮点数 IEEE 754 规范等） |
| [`ICS-中.pdf`](./ICS-中.pdf) | 第二部分（机器级表示与架构） | 程序的机器级表示（x86-64 汇编指令、寄存器体系、控制流、过程调用与运行时栈帧）、体系结构基础 |
| [`ICS-下.pdf`](./ICS-下.pdf) | 第三部分（系统级交互与进阶） | 存储器层次结构、程序性能优化、链接、异常控制流、虚拟内存机制与系统级 I/O |
